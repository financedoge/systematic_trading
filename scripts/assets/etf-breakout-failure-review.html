How to improve without blindly loosening every rule
These are next experiments, not claimed improvements. This diagnosis leaves every fitted parameter unchanged.
    

  1. Make activation and trailing distance work together. An activated trail can still sit below the initial stop or entry price. IAT short fits a 34.35% peak-distance trail; XLY short fits 25.46%. Before heat tightening, these require about 52.3% and 34.2% peak gains respectively just to move the candidate above the entry price, despite much earlier activation. Test a joint parameter constraint or a separately fitted breakeven/profit floor after activation, with the unchanged rule as control. This directly addresses profit giveback; a tighter floor can also cut future winning trends, so it must pass the stronger-case safeguards.
    2. 

  2. Separate cash drag from signal quality. Compare zero-interest cash with actual BIL parking using matching buy/sell costs. This changes the return on idle capital while preserving breakout decisions. It will not fix a bad entry or recover a missed ETF rally.
    3. 

  3. Address missed trends separately from losing trades. For fits spending long periods flat, test a small continuation sleeve rather than replacing every range entry: unchanged baseline plus 0%/25%/50% continuation exposure, with 63/126-session high breakouts selected only inside training. Existing continuation logic remains a control. For entry losses, first inspect initial-risk distance, failed confirmations and delayed exits before tightening stops indiscriminately.
    4. 

  4. Reduce optimizer fragility. Twenty-seven parameters and 241 candidates are a bounded search, not proof of an optimum. Test a smaller set of active parameters and stable neighborhoods, with each ETF still fitted separately. Compare several fixed training-only seeds and an expanding chronological validation schedule; use both the existing fit and buy/hold as controls.
    5. 

  5. Protect performance across the entire pool. A proposed acceptance design is better median net Sharpe and a better lower quartile of net returns, with no more than 1 percentage point CAGR loss or 2 percentage points drawdown deterioration in at least 90% of eligible ETF/domain cases, across 5/10/20 bp and 0/1 added-session execution. Report each historical stronger case explicitly, but do not use this test-period winner list to choose assets or parameters. These thresholds must be frozen before any new experiment.
    6. 

  6. Test portfolio value separately. Carry any candidate into the matched full-pool selector and FR25 overlay, with dynamic adoption and a fixed-monthly control. Account for turnover, costs, drawdown and chronological stability. Better isolated ETF statistics do not by themselves establish a better portfolio.
    7. 

The existing 2023–2026 period has already been inspected. Repeatedly changing rules until those losers improve would fit the evaluation period. New ideas need training-only choice, earlier independent chronologies, and ultimately a later uninspected confirmation period. There is no demonstrated performance-preserving repair yet.
