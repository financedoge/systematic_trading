# Project Skills

These are repository-specific operating playbooks. They are not a substitute for code tests, broker reconciliation, or operator approval.

Use them for recurring platform loops:

- `daily-post-trade-analysis.md`: after-close trading and execution review.
- `continuous-research-loop.md`: ongoing strategy research and challenger evaluation.
- `system-robustness-review.md`: service, data, alert, and recovery review.
- `strategy-promotion-control.md`: research-to-paper-to-live gatekeeping.

Each playbook should produce durable artifacts and update `log.md` when it changes project state, captures an incident, or creates follow-up work.
