# Historical documentation

This folder preserves superseded project-memory narratives for review. It is not
the active operating manual. Start with [the documentation index](../README.md),
[research state](../research-state.md) and [the Kanban](../execution-kanban.md).

## Project history snapshot — October 12, 2026

[project-history-2026-10-12.zip](project-history-2026-10-12.zip) contains the exact
pre-consolidation `log.md`, `docs/execution-kanban.md` and `docs/research-state.md`,
including existing local edits. Original relative filenames are preserved.
[Manifest](project-history-2026-10-12.manifest.json) records file sizes and SHA-256
hashes; every member was decompressed and compared before the active files changed.
[Heading and milestone index](history-index.md) helps find older decisions.

Extract into a separate temporary folder with Explorer or `Expand-Archive`.
Do not extract over current documentation. Links inside the original documents
retain their original repository-relative context.

Historical findings, incidents, approval history and data limitations remain
evidence. The archive is deliberately separate for review, but it is not classified
as disposable: deleting the ZIP removes local historical project memory. No broker,
raw market data, database, frozen research input or execution artifact was removed.
